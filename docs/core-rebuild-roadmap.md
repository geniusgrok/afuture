# 核心策略与风控的持续改造

最终目标仍以原50万元账户的收益、回撤与独立去白银表现衡量。2026年10月4日
的新授权允许替换原策略和风控核心，也允许中间版本收益下降。研究阶段不再
要求每一个父版本立即超过原最终权益门；真实费用、合约单位、成交账本与
信息时序仍是比较基础。代码替换通过匹配研究PR交付，不自动启用实盘。

## 第一阶段：解除旧策略与旧软风控的绑定

旧“成本门”以20日价格趋势外推3日期望收益，它同时表达了方向观点。旧HHI
规则在目标集中度不高于历史中位数时冻结新增仓位。这些是旧策略的一部分，
不能默认对行业相对交易或供需修订同样适用。

`tools/core_rebuild_research.py` 复用原R1账户作为对照，完成另外三个组合：

| 方向过滤 | 软风控 | 用途 |
|---|---|---|
| 原OI确认和趋势成本门 | 原HHI、储备冻结和E1退出 | 原R1对照，复用完整证据 |
| 原过滤 | 新协方差预算 | 检验整组软风控替换 |
| 去除上述方向过滤 | 原软风控 | 检验过滤链是否改变原始信号 |
| 去除上述方向过滤 | 新协方差预算 | 检验两层替换的共同效果 |

新风险核心位于 `afuture/directional_risk.py`，实际账户接线位于
`afuture/directional_robustness.py`。它用目标日前连续63日的具体合约收益，
固定50%样本协方差与50%对角收缩，按15%年化预测波动预算收缩目标，最大
缩放为1。15%是冻结的研究预算，不是回撤承诺。市场观察合约由前日成交量、
持仓量和交割资格决定；收益使用同一具体合约的相邻交易日收盘，不拼接换月
价差。活跃品种历史不足或缺失时目标为零并记录原因，不补造收益。

三项新实验继续共用原整数手投影、保证金适配、真实费用与资金硬约束。新风险
替换的是完整软规则包，结果不能单独归因于HHI。原HHI/储备/E1代码和历史原件
保留用于对照；新入口显式使用新核心。

## 第二阶段：换掉失效的预测核心

若有效证据表明毛收益仍无优势，继续优化整数手不能创造价格预测能力。下一条
路线采用与账户持仓无关的全市场成熟收益样本，替换旧模板轮换与自有成交反馈。
每个当时合格合约都保留事前特征及后来真实收益，未交易的品种也能持续提供
成熟观察；不能在停仓后让训练数据自动枯竭。

固定的首个模型只使用完成日收盘位置、日内与隔夜变化差异、带OI变化的收盘
位置三个特征。目标是同合约入场开盘到五个交易日后开盘的收益，按入场前
20日波动归一化。终点交易日完整结束后才可进入训练；训练仅用最近252个
成熟入场日期，至少126个不同日期和20个品种，每日期样本权重之和为1。
三系数、无截距、单位正则先验；不搜索最优特征天数或正则参数。全池及去AG
分别建样本并拟合。此模型仍可能失败，历史因果成立不构成样本外盈利证据。

## 多轮失败后的分岔

| 观察结果 | 下一项改造 | 不继续消耗的支线 |
|---|---|---|
| 毛收益在多个开发时期均负 | 更换信息来源、预测机制或交易结构 | 同一信号的仓位和阈值扫描 |
| 毛收益为正、成本后为负 | 实际持仓生命周期、必要换月与净额成交 | 不断提高信号门槛挑最好曲线 |
| 连续目标有效、整数账户损失显著 | 与可交易容量一致的资金分配 | 把金额跟踪偏差当成能追回的利润 |
| 非AG贡献改善、全池暂时降低 | 保留该组件，匹配风险和其他有效组件 | 为追旧全池收益立即放大杠杆 |
| 信号被旧过滤或软规则压制 | 检验规则替换后的独立账户与交互效应 | 假定原过滤对所有新信号正确 |
| 数据时点或具体合约标记不合格 | 补版本/时点证据，同时推进其他有效输入方向 | 用代理填补缺失并报告收益 |
| 组合失败 | 分解各组件贡献、风险预算与真实净额成交 | 反复搜索静态混合比例 |

原方向只有在出现新信息、新适用条件或新的结构解释时才重新开启。一个支线
暂停不等于整个项目停止；每项仍可执行的独立分支继续推进。

## 阶段状态与最终验收

- `invalid_evidence`：账本、行情或时序不合格，先修证据，不作经济判断。
- `retain_for_rebuild`：虽未过最终门，但同口径对照改善了成本后贡献、收益/
  回撤关系或真实执行；记录下一次可验证的解释及其推翻条件。
- `replace_mechanism`：当前机制没有证明应继续投入，转向另一责任层或信息源。
- `candidate_for_validation`：达到核心经济目标后，再进行广度、剔除、压力和
  真正新增数据验收。历史开发通过不自动授权真实资金。

阶段改善只是继续研究的理由，不能重新命名为经济目标达成。所有已反复使用
的980日历史与42日近期窗口均是开发数据；不能称为新的独立样本外区间。
自然新数据必须按事前冻结规则积累，收益下降也完整保留。

当前执行器能持续运行已登记的机制与条件分支，未知新机制仍需研究实现。
研究者在本次会话内继续独立分支，与已有后台策略生成服务是不同能力；不得
对未部署的后台执行作承诺。最新源码、实际结果与剩余工作以匹配PR和私库
原件为准，不以本文充当盈利结果或运行状态。
