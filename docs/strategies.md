# 当前策略

策略只输出意图或目标；Broker 成交推进持仓，风控可拒绝、缩小或延后新增风险。平仓、只减仓和硬停机优先。参数与单位见[配置](configuration.md)，执行顺序见[架构](architecture.md)。

## 固定跨期价差

`[[pairs]]` 指定同品种近月、远月；使用同步且同交易日的行情计算 `near - far` 或 `log(near) - log(far)`。滚动窗口仅含已可见样本。买入价差按近月卖一/远月买一，卖出按近月买一/远月卖一计算可成交偏离。

- 正 Z 达 `entry_z` 卖出价差，负 Z 达 `-entry_z` 买入；启用确认时须经过极值回撤，仍满足残余偏离门。
- 趋势斜率、均值回复启发式、半衰期、时段、流动性和扣费后净边际须合格。启发式不等于平稳性检验或收益证明。
- 手数受配置上限、波动预算、深度、保证金和账户限制，只能向下缩减。
- 偏离回到 `exit_z` 退出；`stop_z`、结构变化、持有期、到期、失衡或风险可紧急退出。

内部 `1/-1/0` 是信号状态，不是账户持仓。

## 自动跨期选组

Auto 从当时已挂牌目录筛允许交易所/品种，剔除到期过近、参数或流动性不足的合约，按到期排序构造相邻月份组合。同步样本用于偏离、流动性、均值回复启发式、半衰期和扣费净边际评分；总组合和单品种数量受限，执行复用固定模式。

不能用后来挂牌的合约、当日最终量/OI、缺失腿填充或未来数据改善旧候选。退役只停止新风险，已有持仓继续由正常退出和 Broker 成交管理。

## 方向组合

配置须显式选择 `execution_aligned` 或 `stress90`，与跨期模式账户互斥。固定 Base 包含 96 模板；完整 D 日价格最早决定 D+1 目标，元组合读取此前 11 完整日收益，每 3 日选择最多 3 个在标准/压力成本下均正向的模板。这些常数不是运行时搜索空间。

上一完整交易日成交量/OI 决定具体合约：挂牌、交易所、到期和流动性须合格；合格 incumbent 优先，挑战者须在量和 OI 两项都严格更高才换月。快照缺失、身份不一致或价格未覆盖该日则不开仓。

权重按权益、价格和乘数转为整数手数，再受 gross≤2、每合约手数、多空保证金率/缓冲、资金、亏损、深度、涨跌停、时效和频率门约束。缺可信每手保证金不开仓。调仓先减仓，等待 Broker 确认，重读真实持仓后才考虑开仓；活动委托阻止重复报单。

普通策略在最近完整日收益≤−2% 或最近两完整日样本波动≥3% 时，将下一目标缩到 25%；未完成日盈亏不参与。

## Stress-90

Stress-90 是固定政策名称，不代表成本、风险等级或未来收益。当前纯候选顺序为：

```text
50 品种 Base → 九品种 completed 60m Price×OI confirmation
→ completed close 20/3/15bp cost gate → survivor reallocation → raw HHI
```

flow 在完整 first/last 价格与 OI 证据上判断持仓上升及价格方向；合法零值与 UNKNOWN 不同。survivor 在不创造 support、不改方向、不增加 gross 下，先最小化目标 tracking error，再最小化相对上一 applied target 的 turnover。HHI 与 strictly-prior expanding median 比较。

Stress-90 使用 1x raw candidate 做保证金整数拟合，不重复普通策略 0.25 缩放。completed account path 达 25% reserve 以及 HHI 触发时仅冻结新增风险，保留减仓/退出/反转/合格同品种换月，不能绕过硬风控。reserve 触发持久锁存，净值恢复、重启、账户 rebase 或 epoch 变化不清除。

entry、add、reversal 限固定首窗；真实 CTP 的已认证纯同向换月可在原意图预算内于后续 session 完成，完整条件见[手册](stress90-live-runbook.md#换月与日终边界)。Sim/Shadow 仍限首窗。

batch、固定 bootstrap 与 live incremental 共享纯 primitives。运行仍须固定预热、身份绑定、数据覆盖和现场门；代码接线、历史收益或 CI 不授权实盘。

## 修改边界

信号、模板、品种池、时点、选约/换月、目标大小、风险响应、成本或成交假设改变均是经济行为变化，须验证受影响的完整业务门。策略不得拥有第二套资金、持仓、成交或停机状态；出现恶化先降低或停止风险，不能用同一已观察历史反复调参声称前瞻证据。
