# 当前策略说明

本文描述当前代码会生成什么交易意图，以及策略不能做什么。参数默认值和单位见 [`configuration.md`](configuration.md)，成交、账户和风控顺序见 [`architecture.md`](architecture.md)，术语见 [`glossary.md`](glossary.md)。

所有策略共同遵守：

- 只输出信号或目标仓位，不直接修改现金、权益和真实持仓；
- 只有 Broker 成交事件可以改变账户真相；
- 风控可以拒绝、缩小或延后任何新增风险；
- 平仓、强制减仓和停机优先于开仓；
- 被拒绝的信号不会伪造持仓，但已经消费的市场样本仍会保留，防止同一事件重复触发。

## 1. 固定跨期价差（Calendar）

固定模式由 `[[pairs]]` 指定同一品种的近月和远月合约。每次使用时间同步、交易日一致且通过数值校验的两腿行情，计算：

```text
绝对价差 = 近月价格 - 远月价格
或
对数价格比 = log(近月价格) - log(远月价格)
```

滚动窗口只包含当时已经可见的样本。开仓判断使用实际可成交方向：买入价差按近月卖一和远月买一计算，卖出价差按近月买一和远月卖一计算，而不是使用更乐观的中间价。

### 开仓

- 可卖出价差的 Z 值达到正 `entry_z` 时产生卖出价差意图；
- 可买入价差的 Z 值达到负 `entry_z` 时产生买入价差意图；
- 启用确认模式时，先等待偏离达到极值，再要求至少回撤 `confirmation_retrace_z`，且偏离仍不小于 `min_confirmed_entry_z`；
- 趋势斜率、均值回归稳定度、半衰期、交易时段、净边际和流动性必须同时合格；
- 最终手数不超过 `pairs.volume`，并由波动风险预算、盘口深度、保证金和账户限制继续向下缩小。

### 退出

- 可平仓方向的偏离回到 `exit_z` 内时正常退出；
- 偏离达到 `stop_z` 时紧急退出；
- 绝对价差模式发现均值或波动结构发生显著变化时紧急退出；
- 达到 `max_holding_samples` 时紧急退出；0 表示关闭持有期退出；
- 风控、到期保护、停机或两腿失衡也可以要求退出，且优先级高于策略继续持有。

策略内部的 `1 / -1 / 0` 只表达多价差、空价差或无价差的信号状态，不是账户持仓真相。

## 2. 自动选择跨期组合（Auto）

Auto 复用同一个跨期策略，只自动决定“交易哪一组具体合约”。流程是：

1. 从决策时已经挂牌的 CTP 合约目录或历史时点目录中筛选允许品种和交易所；
2. 剔除距到期日过近、缺少合约参数或流动性不足的合约；
3. 每个品种按到期日排序，只在相邻月份之间构造候选；
4. 使用两腿同步样本计算偏离、流动性、成交量、持仓量、稳定度、半衰期和扣费后净边际；
5. 按评分选择少量候选，同时限制总组合数和单品种组合数；
6. 激活后的组合进入与固定模式相同的策略、风控、执行和记账链。

Auto 不允许：

- 使用后来才挂牌的合约重建过去候选；
- 用当日最终成交量或持仓量回填早先时点；
- 为缺失腿向前填充旧行情；
- 因候选退役而直接删除真实持仓；
- 绕过净边际、两腿时间差、到期或账户风控。

候选退役时，已有风险必须先走正常退出和 Broker 成交；不能把“从候选列表消失”等同于“已经平仓”。

## 3. 方向组合（Directional）

方向组合的信号单位是品种权重，执行单位是具体合约整数手数。当前生产策略是代码中固定的 96 个模板组合；模板族包括趋势、动量、反转、均线、突破和加速度。运行期间不会搜索新的窗口、品种或参数。

### 信号时序

1. 只使用已经完成的连续合约价格数据计算品种信号；
2. 每个模板在自己的固定调仓频率上输出不超过 2 倍总敞口的目标；
3. 元组合只读取此前 11 个完整交易日的模板收益，每 3 日重新选择最多 3 个模板；
4. 候选必须在标准成本和压力成本下都保持正向，排序仍按标准成本表现；
5. 交易日 D 的信号最早用于 D+1，不读取 D+1 收盘或未来收益。

这些数字是当前固定策略的一部分，不是运行时可配置的搜索空间。修改它们属于经济行为变化，必须重新执行完整方向策略验证。

### 选约和目标手数

在 D+1，系统读取上一完整交易日冻结的成交量和持仓量快照：

- 合约必须已挂牌、属于允许交易所和品种，并距离到期日至少 `min_days_to_expiry`；
- 必须达到成交量和持仓量门槛；
- 已有合格持仓合约优先保留；只有挑战合约的成交量和持仓量都严格更高时才换月；
- 没有完整快照、价格历史没有覆盖快照交易日或合约身份不一致时拒绝增加风险。

品种权重按账户权益、具体价格和合约乘数转换成整数手数，再依次受以下限制：

- 目标和实际总名义敞口不超过 2 倍权益；
- 单合约手数上限；
- 多空各自的真实保证金率和保守缓冲；
- 保证金占比、可用资金、单日亏损和总回撤；
- 盘口深度、涨跌停距离、行情时效和报单频率。

整数拟合只能缩小目标，不能为了凑齐组合而增加任何合约手数。缺少正的每手保证金证据时不开仓。

### 状态收缩和调仓

最近一个完整交易日收益不高于 -2%，或最近两个完整日收益的样本波动不低于 3% 时，下一目标缩小到 25%；当前交易日尚未完成的盈亏不能进入这个判断。

调仓严格执行：

```text
计算目标
→ 先生成所有减仓
→ 等待 Broker 确认
→ 下一轮重新读取真实持仓
→ 再考虑开仓
```

目标为零、反转、换月、单日熔断和总敞口超限都走同一条减仓路径。活动委托存在时不会重复报单。

## 4. 当前离线压力候选的边界

历史代号 `Stress-90` 的方向研究候选在固定输入的离线账户模拟中通过了预设压力门。它在目标权重较分散时冻结新增品种和同方向加仓，但允许减仓、退出、反转和同品种换月。

这项“基于历史集中度的新增风险冻结”目前只存在于离线验收组件，没有自动接入实盘 `Directional` 运行链。不能从离线报告推断实盘正在执行该规则，也不能因为离线收益较高就跳过 Shadow、测试柜台、未来数据和极小资金验证。

完整固定输入和结果见 [`stress90-final-evidence.md`](stress90-final-evidence.md)。

## 5. 新增或修改策略的边界

新增策略应只实现以下契约：

```text
已验证的行情和历史状态
→ 交易意图或目标仓位
```

不得创建第二套持仓、资金、成交或停机状态。以下修改都属于经济行为变化：

- 信号公式、窗口、候选选择、参数或品种池；
- 信号可见时点、交易日映射和换月规则；
- 仓位大小、杠杆、保证金或风险阈值；
- 成交价格、手续费、滑点和部分成交假设；
- 训练、验证、样本外或压力情景定义。

这类修改必须有因果性测试、回归测试和修改前后账户结果比较，不能只因为新结果更好就接受。
