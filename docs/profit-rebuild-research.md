# 配对净收益改造

本轮将期限结构核心替换、逐资产风险资格和新信息取得作为独立路线。失败会继续下一个已注册结构，父证据无效只阻塞依赖它的路线。没有窗口、成本、杠杆或阈值网格搜索。

`afuture/curve_rebuild.py` 支持训练前移除 FG/JM 或 SA/FG，并独立重拟合共享或行业模型；随后用固定年度正弦、余弦与曲线水平、变化的交互检验季节风险溢价。成熟五交易日标签、252个入场日回看、126成熟日期和20品种最低覆盖沿用前版。季节和行业偏离收缩固定为20。

`forecast_covariance_portfolio(..., risk_eligibility="per_asset")` 使用同一63个已完成交易日，明确排除缺风险历史或零波动的资产。其余资产共同估计协方差、成本和仓位，排除者保留零目标。旧 `all_assets` 默认保留作匹配对照。这个变更仅作用于预测分配器；账户每日协方差门、整数手、成交记账和硬风险仍使用同一既有离线账户。

`tools/profit_rebuild_research.py` 执行全池和独立去白银池、Base/Stress、历史和近期八格账户。每格初始50万元，共同真实具体合约行情；Base/Stress单边5/15bp、保证金代理12%/15%、缓冲1.25。980日与42日窗口均是已观察开发历史，日线回撤不证明盘中或实盘风险。

阶段性实质收益要求两池压力成本下历史净利至少5000元，并较指定父版本各增利至少5000元、回撤不升，最近两池净盈利且不低于父版本，八格完整且没有硬停机。匹配控制不能算新增收益项；空仓、恢复交易和工程通过也不能算盈利。盈利广度单独核验，阶段门不替代原经济目标和新样本外验证。

本轮冻结输入、每个失败、实际模型审计、逐笔成交、独立现金复核与新信息来源保存在私有证据路径 `runs/afuture-profit-rebuild-20261005`。恢复归档后按其中 `REPRODUCE.md` 的冻结路径执行；源码和数据身份必须与记录一致。不同输入或源码应使用新的活动目录，不覆盖旧账本。

新信息路线继续核对同交割月外盘原油、人民币汇率和国内原油重开数据。bar完成时刻、来源延迟、国内已发生响应与未来入场严格分开；不同分钟接口的开盘价若不一致，不能用较粗数据冒充具体成交证据。具体结果以该路径报告和远端完整回读收据为准。

这些工具仅用于离线研究，不接入生产订单链，也不自动替换 main 默认策略。
